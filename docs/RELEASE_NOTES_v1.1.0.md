## 旅程声音

- 苏区拨弦、湘江低音、遵义疏缓的簧管、雪山风声、草地雨声和陕北的主题回归。托信与告别处留出安静的空拍。
- 草绳、脚步、纸张、铜扣、布料、水声、碗声等随剧情触发，陕北只在对应对白听到远号。
- 点击开始或继续旅程后启用声音。「暂歇 → 阅读、画面与声音」可分别调音量或静音，设置会保留。
- 配乐和音效在本机合成，双击版支持离线播放。修复了离线构建误替换压缩脚本字符的问题。
