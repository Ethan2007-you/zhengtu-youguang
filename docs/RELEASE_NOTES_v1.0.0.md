这是《征途有光：把信送到的人》的首次GitHub发布，包含最新人物演出和单文件游玩版。

## 下载

- **征途有光-双击即玩版.zip**：用于游玩和演示。完整解压后，用Edge或Chrome打开index.html；背景、人物、脚本、样式和剧情已内嵌，运行游戏不需要Node.js或CMD。
- **征途有光-完整开发包.zip**：用于修改和继续开发。包含源码、素材源稿、提示词、普通静态构建、单文件成品、剧情方案和说明文档。

GitHub网页中的HTML文件页面只显示源码；请下载到本机使用。

## 内容

五章十五场、31个选项、五次关键抉择和四种个人结局。七名人物共30张透明姿态素材，按情节表现递鞋、系鞋、托信、包扎、举号、咳嗽、持碗与悲痛。人物与对白为虚构，重大历史主干固定。

## 验证

TypeScript和生产构建、49,152条完整剧情组合、120个代表性存档检查点与149处人物演出检查通过。桌面和手机尺寸在浏览器中目视检查过。

自动浏览器不支持file协议预览，因此未直接实测双击打开；同一单文件的内嵌资源、剧情推进与刷新恢复已通过本机HTTP预览检查。真实手机、指定Chrome129与持续帧率仍未专项验证。

## 开发

安装Node.js 22或更新版本后运行npm ci、npm run dev。修改后使用npm test和npm run build:offline重新验证及打包。详细说明见仓库README、CONTRIBUTING.md、ASSETS.md和VALIDATION.md。
